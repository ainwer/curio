# Security policy

## Reporting a vulnerability

Please report security vulnerabilities privately using GitHub's private
vulnerability reporting:

1. Go to the **Security** tab of the repository.
2. Choose **Report a vulnerability** (or open a private security advisory).
3. Describe the vulnerability, its impact, and, if possible, steps to reproduce.

Do not open a public issue or pull request for a suspected vulnerability. We
will acknowledge your report as soon as we can, investigate it, and work with
you to agree on a disclosure timeline.

## Supported versions

Only the latest commit on `main` is supported. No released versions exist yet;
when releases begin, this policy will be updated to list them explicitly.

## What to include

A good report helps us respond quickly. Where possible, include:

- The affected component and version (or commit SHA).
- A description of the vulnerability and its potential impact.
- Steps to reproduce, or a proof of concept.
- Any suggested mitigations or fixes.

## Expectations

- We will acknowledge receipt of your report and keep you informed of progress.
- We will not publish your report or any details you share without your consent.
- We ask that you give us a reasonable amount of time to fix the issue before
  disclosing it publicly.

Thank you for helping keep Curio and its users safe.
